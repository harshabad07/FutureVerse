## ✨ Features

- **🚀 Hero Section**: Placement statistics counter, quick overview, and action buttons.
- **🧠 Interactive Aptitude Quiz**: 10 multiple-choice questions (Quant, Logic, Verbal, CS) with live progress bar, real-time option validation, explanation box, and final score calculation.
- **💻 Coding Preparation**: Language cards for Python, Java, Data Structures & Algorithms, and Problem-Solving patterns with code templates.
- **📚 Technical Interview Modules**: Core computer science revision topics for DBMS, Operating Systems, Computer Networks, OOP, Software Engineering, and Data Science.
- **🗣️ HR Interview Accordion**: Interactive expand/collapse questions with structural answer formulas (Present-Past-Future) and sample responses.
- **✅ Placement Readiness Checklist**: Interactive checklist with live percentage calculation (`0%` to `100%`) and `localStorage` persistence.
- **🌙 Dark / Light Mode**: Instant theme switching with saved user preference.
- **📩 Form Validation**: Contact form with regex email check and inline error notifications.
- **📱 Fully Responsive**: Custom CSS layout adapted for Desktop, Tablet, and Mobile viewports.

## 🛠️ How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/harshabad07/prepmate-placement-portal.git
   ```
2. Navigate into the project folder:
   ```bash
   cd prepmate-placement-portal
   ```
3. Open `index.html` in your favorite web browser! No backend or installation required.
